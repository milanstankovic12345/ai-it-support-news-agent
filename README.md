# AI IT Support News Agent

An autonomous AI agent that monitors current AI and enterprise IT news,
analyzes business and IT relevance, identifies automation opportunities,
and delivers concise intelligence briefings through Telegram.

## Architecture

Web Search
    ↓
Hermes Agent
    ↓
NVIDIA NIM
    ↓
AI IT News Analyst Skill
    ↓
Opportunity Analysis
    ↓
Telegram

## Technologies

- Hermes Agent
- NVIDIA NIM
- Nemotron
- Web Search
- Custom Hermes Skill
- Telegram
- Cron Automation
- Linux

## Features

- Current AI news monitoring
- Enterprise IT news monitoring
- AI-powered analysis
- Enterprise impact analysis
- Automation opportunity detection
- Side-income opportunity detection
- Telegram notifications
- Scheduled autonomous execution
